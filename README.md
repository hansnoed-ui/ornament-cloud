# ornament-cloud

Einfache statische Website (reines HTML/CSS), die eine Auswahl meiner Claude-Artefakte präsentiert.

- `index.html` – Inhalt; jedes Artefakt ist ein `<article class="card">`-Block
- `styles.css` – Gestaltung (inkl. automatischem Dark Mode)

Lokal ansehen: `index.html` im Browser öffnen.
