Nebeneinander, Nacheinander: vom Zufallsrad zum Möglichkeitsraum

Portfolio · Versuchsanordnung · redaktionelle Fassung V4

Was als interaktives Doppelrad begann, auf dessen gegenläufigen Ringen sich Künstler:innen und Theoretiker:innen zufällig begegnen, ist inzwischen ein kuratierter Möglichkeitsraum aus Konstellationen mit eigener innerer Struktur. Die Texte wurden redaktionell und theoretisch geschärft, und wo einzelne Theoretiker:innen immer wieder auf dieselbe Rolle festgelegt waren, wurde diese Verengung bewusst aufgebrochen. Eine Kartierung nach wiederkehrenden Denkbewegungen, vom Ziehen von Grenzen über das Verzeitlichen und Wiederholen bis zum Situieren von Beobachtung, machte dünne und leere Zonen sichtbar, aus denen gezielt neue Paarungen entstanden sind: Der Zufall des Rads bewegt sich seither in einem Gefüge, das er selbst nicht zeigt. Das Rad erzeugt keine Antworten. Es erzeugt Konstellationen.

Erstellung einer neuen Website mit Claude Code

Website ornament-cloud · entstanden im Dialog mit Claude Code

In einem einzigen langen Gespräch mit Claude Code ist aus einem leeren GitHub-Repository diese Website entstanden: schlichtes HTML und CSS, das drei meiner Claude-Artefakte zeigt. Die Artefakte wurden samt 3D-Bibliothek und Schriften auf die eigene Seite geholt, sodass nichts mehr von fremden Servern geladen wird. Für jede Arbeit hat Claude die Animation Bild für Bild aufgenommen und daraus kurze Vorschau-Schleifen gemacht, deren Format, Tempo und Kontrast wir mehrmals nachjustiert haben. Dazu kamen ein ruhiger Hintergrund aus Lemniskaten und Schleifen, die wiederkehren, aber nie identisch, ein Menü mit drei stark reduzierten Schwarz-Weiss-Symbolen und eine wogende Trennlinie. Jede Rückmeldung wurde zu einem kleinen, überprüften Schritt auf GitHub – der Prozess selbst ist eine Wiederkehr ohne Rückkehr.
