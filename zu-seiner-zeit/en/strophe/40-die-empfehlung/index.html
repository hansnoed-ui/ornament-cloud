The Recommendation

The recommendation returns calculated probability as a possible next world.

The recommendation is the moment at which calculation crosses the boundary of the model. A probability that internally was only a number, a weight or a rank now appears as an object in the world: this song, this person, this video, this route. A recommendation does not compel. That is precisely why it is effective. It occupies a possible next place before a search of one's own has begun, and presents this pre-occupation as help. The prediction thereby becomes socially connectable. What was calculated can be chosen, ignored, shared or rejected. Each of these reactions at the same time produces new traces. A recommendation is therefore selection and measuring instrument in one and the same operation.
