El algoritmo

El ranking algorítmico distribuye oportunidades desiguales para la conexión siguiente.

En las plataformas, procedimientos algorítmicos de selección ordenan contenidos y sugerencias: más o menos relevante, visible o invisible, primero o después. Tales procedimientos pueden calcular probabilidades a partir de datos y traducirlas a un ranking concreto. Para ello hacen falta decisiones previas sobre qué se recoge, se etiqueta y se valora como éxito. El poder de este ranking reside en preparar el presente de forma desigual. Lo que está más arriba tiene más ocasión de desencadenar una conexión posterior; lo que rara vez se muestra pasa desapercibido con más facilidad. Las personas usuarias pueden objetar o elegir de otro modo. Pero también sus desviaciones se encuentran con una selección ya ordenada y pueden volver a entrar como datos.
